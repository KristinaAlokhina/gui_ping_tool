## 🇩🇪 Auf Deutsch

Ein einfaches und benutzerfreundliches grafisches Werkzeug zur Überprüfung der Netzwerkverbindung durch Ping-Anfragen.

### 🚀 Funktionen

- **Intuitive GUI:** Einfache Bedienung über eine grafische Benutzeroberfläche ohne Konsolenbefehle.
- **Echtzeit-Überwachung:** Live-Verfolgung von Ping-Zeiten und der Erreichbarkeit von Hosts.
- **Flexibilität:** Schnelle Überprüfung von IP-Adressen, Netzwerkgeräten und Webseiten.
- **Plattformübergreifend:** Läuft problemlos auf verschiedenen Betriebssystemen (Windows, macOS, Linux).

### 🛠️ Technologien

- Python 3.10+
- Integrierte Module: `os`, `sys`
- Grafisches Framework: Tkinter / PyQt

### 📦 Installation & Start

1. Repository klonen:
    
    ```bash
    git clone <https://github.com/KristinaAlokhina/gui_ping_tool>
    ```
    
2. In das Projektverzeichnis wechseln:
    
    ```bash
    cd gui_ping_tool
    ```
    
3. Skript ausführen:
    
    ```bash
    python gui_ping_tool.py
    ```

## 🇬🇧 In English

A simple and user-friendly graphical tool for checking network connectivity via ping requests.

### 🚀 Features

- **Intuitive GUI:** Easy operation through a graphical user interface without console commands.
- **Real-Time Monitoring:** Live tracking of ping times and host availability.
- **Flexibility:** Quick checking of IP addresses, network devices, and websites.
- **Cross-Platform:** Runs smoothly on various operating systems (Windows, macOS, Linux).

### 🛠️ Technologies

- Python 3.10+
- Built-in modules: `os`, `sys`
- Graphical Framework: Tkinter / PyQt

### 📦 Installation & Start

1. Clone the repository:
    
    ```bash
    git clone <https://github.com/KristinaAlokhina/gui_ping_tool>
    ```
    
2. Navigate to the project directory:
    
    ```bash
    cd gui_ping_tool
    ```
    
3. Run the script:
    
    ```bash
    python gui_ping_tool.py
    ```
