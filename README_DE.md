Ein einfaches und benutzerfreundliches grafisches Werkzeug zur Überprüfung der Netzwerkverbindung durch Ping-Anfragen.

## 🚀 Funktionen
- **Intuitive GUI:** Einfache Bedienung über eine grafische Benutzeroberfläche ohne Konsolenbefehle.
- **Echtzeit-Überwachung:** Live-Verfolgung von Ping-Zeiten und der Erreichbarkeit von Hosts.
- **Flexibilität:** Schnelle Überprüfung von IP-Adressen, Netzwerkgeräten und Webseiten.
- **Plattformübergreifend:** Läuft problemlos auf verschiedenen Betriebssystemen (Windows, macOS, Linux).

## 🛠️ Technologien
- Python 3.10+
- Integrierte Module: `os`, `sys` (oder plattformspezifische Ping-Bibliotheken)
- Grafisches Framework: Tkinter / PyQt (hier passendes Framework eintragen)
